## 📌 대표 프로젝트

### [SmartPantry (SMPA)](링크를-넣어주세요)
AI 기반 식재료 유통기한 관리 & 레시피 추천 서비스 · 4인 팀 프로젝트 (백엔드 담당)
- 영수증/식재료 사진을 로컬 LLM(Gemma, Ollama)이 인식해 유통기한 자동 계산·등록
- RAG 기반 레시피 추천, 유통기한 임박 시 웹 푸시 알림
- Docker 컨테이너(web/ai/proxy/frontend/db) 5개로 분리 배포
- `기획 단계 OCR+YOLO → 개발 중 멀티모달 LLM 단독 방식으로 전환` 등 설계 의사결정 과정 포함
- **담당**: 프론트-백엔드 API 연동, 소셜 로그인/API 키 발급, 백엔드-AI서버-LLM 통신 구조 설계

### [가스 센서 시계열 예측 (LSTM)](링크를-넣어주세요)
머신러닝기초 텀 프로젝트 · LSTM 기반 시계열 예측 모델
- 예측 구간(3초~120초)별 독립 모델 5개 구성, RTX 3080 GPU 환경(Docker)에서 학습
- 결과: 3초 예측 R²≈0.99, 120초 예측 R²≈0.88, 장기 예측에는 window size 30초가 최적

### [문서 스캐너 PWA](링크를-넣어주세요)
React + Vite 기반 모바일 친화형 문서 스캔 웹앱 (Vercel 배포, 백엔드 없음)
- OpenCV.js 기반 엣지 자동 감지 + 수동 원근 보정(호모그래피)
- jsPDF를 이용한 다중 페이지 PDF 내보내기, 전체화면 미리보기

### [LLM 연동 미니 프로젝트 모음](링크를-넣어주세요)
딥러닝프로그래밍기초 과제 · Flask/LangChain 기반 LLM 활용 실습
- 유전 알고리즘 + Flask + LLM을 결합한 선교사와 식인종 게임
- 한국어→영어 LLM 번역을 붙인 ComfyUI 이미지 생성 웹앱
- 멀티 세션 지원 LangChain 챗봇, ComfyUI 연동 이미지 프롬프트 정제 텀 프로젝트
